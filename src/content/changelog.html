0.2.0

Latest November 2026

Rules for each device, not only for the network.

New

  • Profiles block services from a catalog of 43 (TikTok, Roblox, YouTube, Discord and more), one click each.
  • Profiles run on a weekly schedule, such as school nights.
  • SafeSearch and YouTube Restricted Mode, for the whole network or one profile.
  • A tunnel rule can route a whole service.
  • A side panel for any device or domain: its profile and whether it applies right now, a day of activity, the services behind it, and what was blocked and why.
  • Notifications to ntfy, Telegram, Discord, Slack or Gotify when a tunnel stays down or a new device joins.
  • Import from a Pi-hole Teleporter export or an AdGuardHome.yaml, with a preview of what comes over and what can't.
  • A second ferrite can follow the first and answer the same way, so you edit in one place.
  • An MCP endpoint, off by default, so an AI assistant can ask why a site is blocked.
  • Encrypted DNS for your devices: DNS over TLS for Android's Private DNS, DNS over HTTPS for iPhones, Macs and browsers. Each device carries its own name, so its profile goes with it when it leaves the house.
  • ferrite gets the certificate from Let's Encrypt and renews it, given a Cloudflare token. No port has to be open for that.
  • Away from home only the devices you list are answered. An iPhone or a Mac sets itself up from a profile, one tap.
  • DNS over HTTPS shares port 443 with Tunnels.
  • A DHCP server, off until you turn it on, so devices show up under their own names.

Resolver

  • Choose what a blocked name gets: NXDOMAIN, an empty answer, 0.0.0.0 or a block page of your own.
  • An optimistic cache keeps names resolving through an upstream outage.
  • A per-device rate limit, and allowed or denied address ranges.
  • Manual rules take regular expressions.
  • Firefox stays on this resolver instead of switching itself to DNS over HTTPS. iCloud Private Relay and Encrypted Client Hello can be turned off for the network, so devices can't slip past the filter.
  • Upstreams, zones, cache sizes and resolver switches apply at once, with no restart.

Panel

  • A calmer look, a Right now card on the dashboard, and devices grouped by profile.
  • ⌘K finds any setting, device, profile, list or tunnel and takes you to it.
  • Sign-ins last seven days since last use and survive restarts and updates. Settings lists the signed-in browsers and signs any of them out.
  • Device names you gave by hand can be edited.
Upgrading
  • The database moves to schema v12 on first start, and an older ferrite can't open it afterwards. Copy ferrite.db first if you may roll back.
  • [proxy] alert_webhook moves to [notifications] by itself.
  • The panel asks for the password once more.

0.1.10

2 November 2026 On GitHub

A security release for the TLS and QUIC stack, and a round of panel work.

Security

  • rustls 0.23.46 closes four advisories, among them a ServerHello that could downgrade later connections to classical key exchange, and up to 1 GiB allocated decompressing a certificate before it is verified.
  • quinn-proto 0.11.19 fixes five ways a DoQ peer could crash ferrite or grow its memory without bound.
  • The distrusted emSign intermediates are no longer trusted.

New

  • Block or allow a domain in one click from the query log or the dashboard, with an undo.
  • Pause filtering for five minutes to an hour, for the whole network or one device.
  • Back up or restore the whole configuration as a single file.
  • Subscription lists refresh on their own every 12 hours.

Improved

  • A restart after an upgrade no longer holds DNS back while device profiles rebuild.
  • Blocklists and allowlists share one implementation. Config, API and blocking decisions are unchanged.
  • Repeated queries fold into one line, each tunnel has its colour and each device an icon, and every page fits a phone.
  • The German, Spanish and French translations are proofread.

0.1.9

30 September 2026 On GitHub

A lighter hot path, and storage you choose.

Faster

  • Queries are read and patched on the wire instead of decoded and rebuilt, and on Linux UDP moves in batches. CPU per query drops from ~139 µs to ~19 µs.
  • A list refresh that changed nothing builds nothing, and a profile recompiles only when its own lists move.
  • The refresh peak on a million-domain list fell from 96 MB to 50 MB.

Storage and privacy

  • The database holds only what ferrite observed. Everything you configure lives in config.toml.
  • SQLite at a path picked from the box's mounts, or a RAM-only backend, with a size cap and 30 days of history by default.
  • The compiled blocklist can sit in RAM too, sparing an SD card.
  • Switches that stop query logging and statistics, device inventory included.

0.1.8

2 August 2026 On GitHub

WireGuard in the kernel.

  • Tunnels can run on the kernel backend: ferrite builds its own wg interface over netlink and steers only its own traffic through it, so crypto uses every core.
  • Proxied bytes move with splice(2) and never enter user space.
  • Blocking wins over routing: a blocklisted subdomain stays blocked under a routed domain.
  • A ceiling on the TTL devices see, so list, rule and profile changes reach them within a minute.
  • The Linux download is ~20 MB instead of ~171.

0.1.7

20 July 2026 On GitHub

Profiles for devices.

  • Per-device blocklist profiles with their own block and allow entries.
  • Subscribable allowlists.
  • A default-deny mode that keeps local names working.
  • Latency probes decide when fail-closed routing kicks in, and a webhook alerts when a tunnel is down.
  • Prometheus metrics at /api/metrics and traffic stats per tunnel.

0.1.6

12 July 2026 On GitHub

Memory that stays flat.

  • The mimalloc allocator, bounded internal caches and memory stats keep a long-running process small.
  • Tunnel supervision hardened against stalls and reconnect churn.
  • The Docker image exposes port 443.

0.1.5

25 June 2026 On GitHub

DNSSEC over any upstream.

  • Signatures survive DoT and plain upstreams: the response is forwarded as it came instead of being rebuilt.
  • Idle tunnel connections are closed after a timeout, so memory stays flat under heavy routing.

0.1.4

21 June 2026 On GitHub

Routing per device.

  • Routing rules scoped to chosen devices.
