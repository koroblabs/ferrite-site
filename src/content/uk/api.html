REST API

Той самий API, на якому працює панель

Усе в панелі робиться викликами цього API, тож те, що ви робите руками, зможе зробити й скрипт. На вході JSON, на виході JSON, за шляхом /api на порту панелі.

Авторизація

Усі маршрути /api/* вимагають API-ключа (заголовок X-API-Key) або cookie сесії від POST /api/auth. Ключ задається в налаштуваннях. Сам /api/auth відкритий для всіх.

Одразу чи після перезапуску

Більшість налаштувань діє одразу. Деякі (адреси прослуховування, розміри кешу, upstream-сервери, DNSSEC/ECS) потребують перезапуску, і відповідь каже, які саме.

Статистика й лог запитів

GET /api/stats/summary

Поточні лічильники (усього / заблоковано / з кешу / upstream), прямо з пам'яті.

GET /api/stats/timeseries

24 години по 10 хвилин, для графіка.

GET /api/stats/top-domains · top-blocked · top-clients

Рейтинги за всю збережену історію.

GET /api/stats/system

CPU процесу, пам'ять, мережа, диск, навантаження.

GET /api/queries

Лог запитів з фільтрами (за пристроєм, статусом, доменом, часом).

DELETE /api/queries

Очистити збережену історію запитів.

GET /api/logs

Останні записи лога сервера з пам'яті (курсор для нових записів + мінімальний рівень).

Пристрої

GET /api/clients

Пристрої, згруповані за іменем, з їхніми IP та MAC, які бокс про них дізнався.

GET /api/clients/{device}/stats

Один пристрій детально: лічильники, його найчастіші й заблоковані домени, сервіси за ними, активність по 10 хвилин.

GET · POST /api/clients/aliases

Переглянути або задати власне ім'я для IP/MAC.

DELETE /api/clients/aliases/{key}

Прибрати власне ім'я.

Фільтрація

GET · POST /api/blocklist/blacklist · whitelist

Переглянути або додати власні записи блокування чи дозволу.

DELETE /api/blocklist/blacklist/{domain} · whitelist/{domain}

Видалити запис.

GET /api/blocklist/check/{domain}

Чому заблоковано: рішення, список чи правило, що спрацювало, і запис дозволу, який його звільнив.

GET /api/breakage

Імена, які блокує список і які пристрій раз у раз питає, користуючись їхнім сайтом: схоже, блок їх зламав. Разом з іменами, відкладеними вбік.

POST /api/breakage/ignore · DELETE /api/breakage/ignore/{domain}

Лишити ім'я заблокованим, не пропонуючи його, або скасувати це.

GET · POST /api/lists

Переглянути або додати підписку (URL + назва).

PATCH · DELETE /api/lists/{name}

Увімкнути, вимкнути чи видалити список.

POST /api/lists/refresh · /api/lists/{name}/refresh

Завантажити наново всі списки або один.

GET · POST /api/allowlists

Підписки на списки дозволу: домени з них ніколи не блокуються. Працює так само, як /api/lists (PATCH · DELETE /{name}, refresh).

GET · PUT /api/blocklist/profiles

Профілі пристроїв: набори списків, власні винятки, заблоковані сервіси, розклад, SafeSearch, режим «тільки дозволене», і чи діє кожен просто зараз.

GET /api/services

Каталог сервісів: id, назва, категорія й домени кожного.

GET · PUT /api/blocklist/services

Сервіси, заблоковані для всієї мережі.

GET · PUT /api/blocklist/safe-search

SafeSearch і обмежений режим YouTube для всієї мережі.

GET · POST /api/blocking/pause · /api/blocking/resume

Пауза фільтрації на кілька хвилин, для всього боксу чи одного пристрою, і дострокове її завершення.

DNS, тунелі й інструменти

GET · POST /api/custom-records

Переглянути або додати локальний запис A / AAAA / CNAME.

DELETE /api/custom-records/{domain}

Видалити запис.

GET · PUT /api/proxy

Налаштування вибіркової маршрутизації: виходи (тунелі) і правила. Приватні ключі WireGuard у відповіді на GET приховані.

GET /api/tools/resolve?name=&type=

nslookup через ваші upstream-сервери (будь-який тип запису).

GET /api/tools/whois?query=

WHOIS, сервер для якого підказує IANA.

Моніторинг

Метрики для Prometheus, якщо у вас уже є моніторинг: ті самі лічильники, які читає вбудований дашборд, у текстовому форматі Prometheus. До них є готовий дашборд для Grafana.

Швидка перевірка 
curl -H 'X-Api-Key: YOUR_API_KEY' http://ferrite.lan/api/metrics
prometheus.yml, налаштування збору 
scrape_configs:
  - job_name: ferrite
    metrics_path: /api/metrics
    authorization:
      credentials: YOUR_API_KEY
    static_configs:
      - targets: ["ferrite.lan:80"]
Дашборд для Grafana Завантажити 
Dashboards → New → Import → завантажте JSON,
потім виберіть джерело даних Prometheus. Там швидкість
запитів, кеш, стан виходів, RTT перевірок, трафік,
спрацювання правил і пам'ять процесу.
GET /api/metrics

Текстовий формат Prometheus (версія 0.0.4). Авторизація та сама, що й для решти API: API-ключ передається як Authorization: Bearer (у Prometheus це authorization.credentials) або як X-Api-Key у заголовку.

Що експортується

Лічильники запитів за результатом, показники кешу й списків блокування, пам'ять і файлові дескриптори процесу, а для кожного виходу стан, RTT перевірок, трафік і збої, плюс лічильники спрацювань кожного правила. Таблиці по доменах навмисно не експортуються: кількість значень міток у них нічим не обмежена. Id виходів і шаблони правил обмежені конфігом, тож вони є.

Збирати дешево

Кожне значення береться з лічильників, які сервер і так веде. Збір не блокує гарячі шляхи DNS чи проксі, тож короткі інтервали підходять.

Налаштування, авторизація й оновлення

GET · PATCH /api/settings

Прочитати конфіг або змінити його частину (секрети приховані). Поля, які потребують перезапуску, позначені у відповіді.

GET /api/storage/locations

Точки монтування, де можуть лежати база чи кеш списків блокування, з вільним місцем і позначкою, чи це RAM.

GET · POST · DELETE /api/auth

Перевірити сесію · увійти (пароль) · вийти.

GET · DELETE /api/auth/sessions[/{id}]

Браузери, в яких виконано вхід: звідки й коли кожен увійшов. Можна вийти з одного або з усіх, крім вашого.

GET · PUT /api/notifications · POST /notifications/test

Адреса вебхука й формат (ntfy, Telegram, Discord, Slack, Gotify, JSON), які події туди йдуть, і тестове надсилання.

GET /api/config/export · POST /api/config/import

Зберегти або відновити всю конфігурацію одним файлом.

POST /api/mcp · GET · PUT /api/settings/mcp

Model Context Protocol для AI-асистентів (з'ясувати, чому сайт не працює, пристрої, тунелі, а якщо дозволено, то й зміни), а також чи він увімкнений і чи може щось змінювати. За замовчуванням вимкнений.

GET /api/update/check

Перевірка нових релізів сервера й панелі (результат кешується).

POST /api/update/server · /api/update/web

Завантажити й застосувати реліз на ходу.
